CoTeg 🚀

A comprehensive multi-stack development platform featuring AI-powered dating applications and agricultural management systems. Built with modern web technologies including React, Rust, and Next.js.

🚀 Features

AI-powered dating platform with real-time chat and video calling

Agricultural management system with inventory and batch tracking

Multi-vendor marketplace with financial management

Role-based access control for different user types

Real-time messaging and WebSocket integration

🛠️ Tech Stack

Frontend: Vite + React 18 + TypeScript + Tailwind CSS
Backend: Rust (Axum, SeaORM, PostgreSQL)
Admin Dashboard: Next.js 14 + TypeScript + Tailwind CSS

🚀 Getting Started
# Clone the repository
git clone <your-repo-url>
cd CoTeg

# --- Frontend Setup ---
npm install
npm run dev &  # Starts frontend in background

# --- Backend Setup ---
cargo build
shuttle run
